# 06 - Cara Mengubah Program

Bab ini membantu saat ingin mulai mengubah isi program.

## Mulai dari Hal Kecil

Contoh perubahan kecil:

- mengganti teks di layar
- mengubah nama jaringan
- mengubah batas suhu
- mengganti tulisan di halaman web

Kalau masih baru, jangan langsung ubah banyak bagian sekaligus.

## Cara Aman

1. Ubah satu hal saja.
2. Simpan.
3. Coba lagi.
4. Kalau gagal, lihat bagian yang terakhir diubah.

Cara ini membuat kesalahan lebih mudah dicari.

## File yang Sering Diubah

- `src/Display.cpp`
- `src/Config.cpp`
- `web-dashboard/app.js`
- `web-dashboard/index.html`
- `web-dashboard/styles.css`
- `google-apps-script/Code.gs`

## Bagian Mana Untuk Perubahan Apa

- kalau mau ubah tulisan layar, lihat `src/Display.cpp`
- kalau mau ubah setelan bawaan, lihat `src/Config.cpp`
- kalau mau ubah tampilan web, lihat file di `web-dashboard/`
- kalau mau ubah catatan online, lihat `google-apps-script/Code.gs`

## Tips

- jangan ubah banyak hal sekaligus
- baca komentar di file dulu
- lihat [docs/GLossary.md](/home/dhimasardinata/Dokumen/server/docs/GLossary.md) kalau ada kata yang tidak paham

## Latihan Kecil

Pilih satu perubahan kecil, misalnya:

- ganti teks di layar
- ganti nama jaringan
- ganti warna tombol web

Lalu pikirkan file mana yang paling mungkin harus diubah.

# Jalur Belajar C++23

Ini jalur belajar dari nol sampai cukup mahir untuk membaca dan menulis program C++23.

Semua contoh di jalur ini diarahkan ke gaya yang sering dipakai di ESP32, jadi kamu akan lebih sering lihat `Serial`, `pinMode`, `digitalWrite`, sensor, dan relay daripada contoh layar komputer biasa.

## Cara Pakai

1. Baca dari atas ke bawah.
2. Kerjakan satu bab dulu sebelum pindah ke bab berikutnya.
3. Kalau ada kata yang belum paham, buka [docs/GLossary.md](/home/dhimasardinata/Dokumen/server/docs/GLossary.md).
